# Statistics Practice Lab
Static, dependency-free GitHub Pages study site for EGN 3443 Exam II.
Upload index.html to the root of a repository. In Settings → Pages, choose Deploy from a branch, main, /(root), Save. Open the Pages URL after deployment.
Progress is stored locally in the browser. Audio uses browser speech synthesis where supported. No accounts or backend needed.
Sources: supplied Recitation 8, Recitation 9, Fall 2025 Exam II. Some stems shortened; Q6 adapted to match two-sided solution.
